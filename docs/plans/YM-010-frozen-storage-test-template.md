## 2. 評価日ごとの記録

評価予定: 冷凍開始から 1週・1か月・2か月・3か月・（任意で）4か月。各回、同じロットから最低2袋を評価する。

| 評価日 | 経過日数 | 袋・真空の状態（破れ・空気混入） | 霜・乾燥（冷凍焼け） | 色  | 香り（異臭の有無） | カビ・異物 | 焼いたときの食感（伸び・割れ・硬さ） | 味  | 判定（○/△/×） | 写真リンク | 記録者 |
| ------ | -------- | -------------------------------- | -------------------- | --- | ------------------ | ---------- | ------------------------------------ | --- | ------------- | ---------- | ------ |
|        |          |                                  |                      |     |                    |            |                                      |     |               |            |        |

- ×が1つでも出たら、その時点の経過日数を記録し、Humanへ報告する。公開表示の変更はHumanが判断する。
- 官能評価は2人以上で行うと記録の信頼性が上がる。

## 3. 解凍・焼き方の実地検証

同じロット・同じ評価日に、方法ごとに1枚ずつ比較する。

| 方法                                    | 電子レンジの出力・時間 | 水・ラップ       | トースターの出力・時間 | 結果（表面・中心の状態、所要時間） | 推奨（○/△/×） |
| --------------------------------------- | ---------------------- | ---------------- | ---------------------- | ---------------------------------- | ------------- |
| A: 公開文言どおり                       | 500W・約30秒           | なし             | 焼き色がつくまで       |                                    |               |
| B: ブランド情報シートどおり             | 500W・30秒             | 水をつけてラップ | 焼き色がつくまで       |                                    |               |
| C: 凍ったままトースター                 | なし                   | なし             | 焼き色がつくまで       |                                    |               |
| D: 冷蔵庫で自然解凍してから焼く（任意） | なし                   | なし             | 焼き色がつくまで       |                                    |               |

- 機種差が大きいので、使ったレンジ・トースターの機種と出力を記録する。
- 結論が出たら、HP（`frozenCookingNote`）、BASE、レシピ（/recipes/mochi-yakikata）を同じ文言にそろえる。変更はHumanが承認してから行う。
