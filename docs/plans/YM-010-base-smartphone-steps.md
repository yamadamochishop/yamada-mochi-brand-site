# YM-010 BASE スマホ操作手順（年末商戦向け）

- 対象: BASE ショップ `https://yamadamochi.thebase.in/`
- 作成: 2026-10-09（Claude Code。BASE管理画面は操作していない。公開ページの閲覧結果にもとづく）
- 使い方: 上から順に、1項目ずつ実施する。各項目の「確認」で結果を見てから次へ進む。
- 実施の判断: 優先1・2（並び順・カテゴリ）はショップの公開表示を変える操作です。**計画書の H-10（並び順・カテゴリを変えるか）を Human が「変える」と承認し、切り替え日を決めてから**行います。承認がなければ実施しません。優先3・4は確認と記録だけで、ショップの設定は変えません。
- 注意: BASEアプリのメニュー名は、アプリのバージョンで変わることがある。見つからない場合は、ブラウザ版の管理画面（`https://admin.thebase.com/`）で同じ名前のメニューを探す。
- 変えないもの: 商品価格、送料設定、商品URL、原材料・アレルゲン・保存方法・賞味期限の欄（下の「Human判断待ち」が決まるまで）。

## 現状（2026-10-09 公開ページで確認）

- BASEトップの並び（スマホ）: 常温6袋 → 常温6袋ギフト → 選べる6袋 → 単品4枚入り×6 → 単品6枚入り×6 → 常温12袋 → 常温12袋ギフト → 冷凍便4商品。冷凍便は一番下（約11画面スクロールした位置）。
- 冷凍便6袋ご自宅用の送料表: 関東・信越・北陸・東海・近畿 1,180円、北海道 2,070円、沖縄 2,060円 ほか。常温便より各地域+300円。
- 冷凍便ページの賞味期限欄: 「商品表示をご確認ください」。
- 冷凍便ページの最短お届け日: 10/9閲覧時「最短で10月12日(月)」。

## 優先1: 冷凍便を上に並べる（所要5分・H-10の承認と切り替え日の確定後）

1. BASEアプリで「商品管理」を開く。
2. 並び替え（ドラッグで順番を変える操作）を開く。
3. 次の順に並べる。
   1. 【冷凍便・ご自宅用】12袋セット
   2. 【冷凍便・ご自宅用】6袋セット
   3. 【冷凍便・贈りもの用】6袋ギフト
   4. 【冷凍便・贈りもの用】12袋ギフト
   5. 【常温便・贈りもの用】6袋ギフト
   6. 【常温便・ご自宅用】6袋セット
   7. 【常温便・ご自宅用】12袋セット ／ 【常温便・贈りもの用】12袋ギフト
   8. 選べる6袋セット
   9. 単品（4枚入り → 6枚入り）
4. 保存する。

確認: スマホのブラウザで `https://yamadamochi.thebase.in/` を開き、最初の商品が冷凍便になっている。

戻すとき: 元に戻すかどうかと戻す日も H-10 で Human が決める（推奨: 1月上旬）。決まった日に、常温セットを先頭に戻す。決まっていなければ戻さない。

## 優先2: 「冷凍便」カテゴリを作る（所要10分・H-10の承認と切り替え日の確定後）

1. BASEの「Apps」で「カテゴリ管理」Appを探す。未インストールならインストールする（無料App）。
2. カテゴリを作る: 「冷凍便（年末年始のストックに）」「贈りもの・お歳暮」「単品」。
3. 冷凍便4商品を「冷凍便（年末年始のストックに）」に、贈りもの用4商品と選べる6袋を「贈りもの・お歳暮」に、単品を「単品」に割り当てる。
4. 作ったカテゴリのページを開き、アドレスバーのURLをコピーしてClaudeに渡す（公式HPの追従購入バーや冷凍便ボタンの行き先に使える）。

確認: ショップのメニューに3つのカテゴリが出て、「冷凍便（年末年始のストックに）」を押すと冷凍便4商品だけが表示される。

## 優先3: 冷凍12袋の送料を確認する（所要5分・確認と記録だけ）

1. スマホのブラウザで【冷凍便・ご自宅用】12袋セットのページを開く。
2. 「送料は地域やサイズにより異なります」の「詳細を見る」を押し、地域別の送料をスクリーンショットする。
3. 2商品を同時に買ったときの送料は、まず管理画面の配送設定（冷凍便の送料の設定内容）を**見るだけ**で確かめる。設定は変えない。
4. 管理画面で分からない場合だけ、冷凍便6袋セットと冷凍便12袋セットを1つずつカートに入れ、購入手続き画面に表示される送料を見る。
   - **「注文を確定する」など、注文を送信するボタンは押さない。** 決済方法によっては、支払いより前の操作で注文が確定することがある。
   - 注文の送信前に送料が表示されない場合は、そこで中止し「未確認」と記録する。
   - 終わったらカートを空にする。

確認: 次の3点をClaudeに伝える（WP-4・H-9の判断材料）。

- 冷凍12袋の地域別送料は、冷凍6袋と同じか
- 2商品を同時に買ったとき、送料は1回分か2回分か
- 12袋が冷凍便の1箱に収まるか（梱包の実情）

## 優先4: 最短お届け日の表示を確認する（所要5分・確認と記録だけ）

1. 冷凍便商品の発送までの目安日数の設定を開く（商品編集画面、または発送関連の設定）。設定は変えない。
2. いま設定されている日数と、受注後に製造・真空包装・冷凍して発送するまでの実際の日数を、それぞれ記録する。
3. 食い違っていた場合は、正しい日数と適用する商品を決めて（H-6と一緒に判断）から、設定を直す。

確認: 記録した2つの日数をClaudeに伝える。

### 年末案内の文例（H-6が決まってから使う。空欄は推測で埋めない）

```
【年末年始のお届けについて】
・年内お届けの受付締切：常温便 ◯月◯日（◯）／冷凍便 ◯月◯日（◯）
・年内の最終発送日：◯月◯日（◯）
・年始の発送開始：◯月◯日（◯）
ご注文が集中する時期のため、お早めのご注文をおすすめします。
```

公式HPにも同じ日付を出す場合は、Claudeに日付と表示期間を伝える。HP側には、確定した日付・表示期間・確定日を設定ファイル（`data/winter-campaign.ts`）に入れれば表示される仕組みを用意している（PR merge後。見出しは「年末年始のお届けについて」）。
