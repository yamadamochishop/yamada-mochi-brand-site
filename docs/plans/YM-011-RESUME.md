## 4. 同梱紙の再出力方法

- 元データ: Drive の `同梱紙_原稿.html` と `qr-recipes.svg`（同じフォルダに置いてから PDF 化する）。
- QR の中身: `https://www.yamadamochi.com/recipes?utm_source=insert&utm_medium=print&utm_campaign=frozen_2026`。macOS の CoreImage（`CIQRCodeGenerator`、誤り訂正M）で生成し、`CIDetector` で読み取りを確認した。
- PDF化: Google Chrome のヘッドレス印刷（`--headless=new --no-pdf-header-footer --print-to-pdf`）。Chrome は自分では終了しないため、毎回別の `--user-data-dir` を使い、PDF ができたら `pkill` する。`body` に `review` クラスを付けると確認用（未確定の印と出典つき）、`a4` クラスと `.pair` で A4 2面付けになる。
