## 4. 公開後の比較方法

1. 公開日 D、公開時刻、公開コミット、`updatedAt` の値を記録します。
2. 公開翌日から7日・28日の完全日（D+1〜D+7、D+1〜D+28）を、同じ長さの公開前期間（D−7〜D−1、D−28〜D−1）と比べます。GSC は集計に2〜3日遅れるため、期間終了の3日後以降に取得します。
3. 条件は本ファイルと同じにします（GSC: ページ完全一致・ウェブ。GA4: 同じ正規表現、チャネル、本番ホスト）。GA4 の探索は直近2か月しか遡れないため、公開後の取得は2か月以内に行うか、標準レポートを使います。
4. 指標は分けて評価します。
   - 検索: クリック、表示回数、CTR、平均順位、レシピギャラリー（GSC）
   - 自然検索の流入と質: Organic Search のセッション、エンゲージメント率（GA4）
   - 導線: `recipe_view` あたりのクリック数（GA4）。購入率やセッション遷移率と呼びません。
5. 季節性: 対象期間は年末年始の餅需要が高まる時期で、公開前の3か月でも流入は右肩上がりです。公開後の増加をすべて改修効果とはみなしません。次の対照と並べて判断します。
   - サイト全体の検索クリックに対する対象2ページの割合（基準値 70.2%）
   - 改修していない他のレシピページの同期間の伸び
   - クリック数より季節の影響を受けにくい CTR と平均順位
6. 公開後の GA4 本番受信の確認と、カスタムディメンションの登録は [YM-012-measurement.md](YM-012-measurement.md) のとおり Human が承認の範囲で行います。登録前のデータには遡って適用されません。
