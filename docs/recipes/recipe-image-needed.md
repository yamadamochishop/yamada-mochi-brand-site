# レシピ画像 未設定リスト（recipe-image-needed）

作成日: 2026-09-15 ／ 対象: `data/recipes.ts` の公開レシピ13件（すべて `mainImage` 未設定）

## この文書の使い方

- 画像ができたら `public/images/recipes/<slug>.webp` に置き、`data/recipes.ts` の該当レシピに
  `mainImage: { src, alt, role: 'primary', sourceType: 'original_photo' | 'generated' }` を追加する。
  それだけで詳細HERO・一覧カード・OGP・Recipe構造化データが有効になる。
- AI生成画像を使う場合は **必ず `sourceType: 'generated'`** を付ける。カードと詳細に
  「盛り付けイメージ」の注記が自動で出る。注記なしで実写のように見せない。
- 投入順は Search Console の表示回数・クリック数が取れてから決める
  （`popularity` を転記 → `scripts/recipe-inventory.mjs` で棚卸し表を再生成 → 上位から撮影）。
  それまでの暫定順は、商品名で検索される固有商品（昆布餅・たまり餅・海老餅・豆餅）を優先する。

## 共通ルール

| 項目                       | ルール                                                                                                 |
| -------------------------- | ------------------------------------------------------------------------------------------------------ |
| aspect ratio               | 4:3 横位置（一覧カード・詳細HERO・OGPで共用）。中央に主題を置き、上下トリミングに耐える構図にする      |
| 世界観                     | 飛騨高山の家庭の食卓。自然光、木・陶器・和紙のような素材感。派手な演出やスタジオ照明にしない           |
| 商品の見え方               | お餅は山田もち店の「切り餅（角餅）」。丸餅・のし餅・杵つき演出・木臼・職人が搗く場面は描かない         |
| 文字・ロゴ                 | 画像内に文字・ロゴ・架空のパッケージを入れない                                                         |
| 人物                       | 顔を入れない（手元までは可）                                                                           |
| AI生成の共通NG             | 実在しない包装、他社商品に見える見た目、過剰なツヤ・合成感、湯気や光の誇張、材料にない具材の追加       |
| 実写推奨の基準             | 商品そのものの見た目（豆・黒ごま・海老・昆布・よもぎの色味・たまりの色）が主題になるレシピは実写で撮る |
| AI盛り付けイメージ可の基準 | 具材やソースでお餅がほぼ覆われ、商品の固有の見た目が主題にならないレシピ。注記付きで暫定使用可         |

## レシピ別

### 1. `mochi-yakikata` お餅のおいしい焼き方

- 推奨構図: トースターから出したばかりの白い切り餅1〜2個を小皿に。表面にうっすら焼き色、少し膨らんだ状態。醤油皿を脇に添えてもよい
- 必須食材: 山田もち店の切り餅（白餅）
- NG表現: 丸餅、網焼き・炭火の演出、真っ黒な焦げ
- alt案: 「トースターで焼いて表面に薄く焼き色がついた山田もち店の切り餅」
- 推奨: **実写推奨**（ブランドの基本。商品そのものが主題）

### 2. `isobeyaki` 山田家の磯辺焼き

- 推奨構図: 砂糖醤油を絡めた焼き餅を焼き海苔で包んだもの1〜2個を皿に。海苔の艶と醤油の照りが見える寄り
- 必須食材: 白餅、砂糖醤油（照り）、焼き海苔
- NG表現: 丸餅、串刺し、海苔なし、醤油だれの過剰な量
- alt案: 「砂糖醤油を絡めて焼き海苔で包んだ山田家の磯辺焼き」
- 推奨: **実写推奨**（「山田家の」と冠する看板レシピ）

### 3. `ebi-mochi-cheese-pizza` 海老餅の簡単チーズピザ

- 推奨構図: 焼いた黒ごま海老餅の上でチーズが溶けて少し流れている状態。餅の縁に黒ごまと海老の赤い粒が見える
- 必須食材: 黒ごま海老餅（黒ごま・海老の粒が見えること）、とろけるスライスチーズ
- NG表現: トマトソース・バジル等のピザ具材の追加、白餅に見える描写
- alt案: 「焼いた黒ごま海老餅にとろけるチーズをのせた海老餅のチーズピザ」
- 推奨: **実写推奨**（黒ごま海老餅の見た目が主題。AIでは商品を再現できない）

### 4. `kombu-mochi-ozoni-fu` 昆布餅のお雑煮風

- 推奨構図: 木のお椀に焼いた昆布餅1個、澄んだ薄い鰹だし。昆布の粒が餅の表面に見える。具材なし
- 必須食材: 昆布餅、鰹だし
- NG表現: 具だくさんの雑煮（鶏肉・人参・小松菜など）、味噌仕立て、丸餅
- alt案: 「焼いた昆布餅に薄めの鰹だしを注いだお雑煮風」
- 推奨: **実写推奨**（昆布餅の見た目が主題）

### 5. `age-mame-mochi` カリッと揚げ豆餅

- 推奨構図: 約2cm角に切って揚げ、膨らんでカリッとした三色豆餅を小鉢か紙に盛り、塩を軽くふった状態。豆の色（三色）が断面に見える
- 必須食材: 三色豆餅（豆が見えること）、塩
- NG表現: 白餅のあられに見える描写、大量の油、揚げ鍋のクローズアップ
- alt案: 「約2cm角に切って揚げ、塩をふった三色豆餅」
- 推奨: **実写推奨**（三色豆餅の見た目が主題）

### 6. `yomogi-mochi-zenzai` 焼き草餅のぜんざい

- 推奨構図: 椀につぶあんのぜんざい、焼き色のついた草餅が1個のぞく。よもぎの緑と小豆の色の対比
- 必須食材: 草餅（緑）、つぶあん
- NG表現: 白玉・栗など材料にない具、白餅、こしあんの汁粉に見える描写
- alt案: 「つぶあんを溶かしたぜんざいに焼いた草餅を入れた焼き草餅のぜんざい」
- 推奨: **実写推奨**（草餅の色味が主題）

### 7. `tamari-mochi-butter-pepper` たまり餅のバター黒胡椒

- 推奨構図: 焼いたたまり餅（醤油色）の上に無塩バターがひとかけ、削った黒胡椒。バターが少し溶けかけ
- 必須食材: たまり餅（茶色みのある餅）、バター、黒胡椒
- NG表現: 白餅にバター、醤油を後がけした描写、みたらし団子に見える丸い形
- alt案: 「焼いたたまり餅に無塩バターと黒胡椒をのせたバター黒胡椒」
- 推奨: **実写推奨**（たまり餅の色が主題。SEO上も「たまり餅」の固有名詞で検索される）

### 8. `garlic-butter-mochi` ガーリックバター餅

- 推奨構図: 焼き色のついた白餅2切れにガーリックバターが塗られ、再加熱で表面が少し色づいた状態。小皿
- 必須食材: 白餅、ガーリックバター
- NG表現: パセリ・チーズなど材料にない追加、バゲットのようにパンに見える描写
- alt案: 「ガーリックバターを塗ってトースターで焼いた白餅」
- 推奨: **AI盛り付けイメージ可**（注記必須）。実写に差し替えるまでの暫定

### 9. `mentaiko-mayo-mochi` 明太子マヨ餅

- 推奨構図: 焼いた白餅の上に明太マヨが塗られ、焼き目がつき、刻み海苔を少し。1切れの寄り
- 必須食材: 白餅、明太子、マヨネーズ、刻み海苔
- NG表現: 大葉・チーズなど材料にない追加、明太子を丸ごと乗せた描写
- alt案: 「明太マヨをのせて焼いた白餅に刻み海苔を散らした明太子マヨ餅」
